
# Calculadora IMC

## Descripción

Esta aplicación para Android permite calcular el Índice de Masa Corporal (IMC) a partir del peso y la altura del usuario.

El proyecto se ha desarrollado con Kotlin y Jetpack Compose, utilizando componentes de interfaz para facilitar la introducción de datos y mostrar el resultado de forma visual.

## Funcionalidades

- Introducir el nombre del usuario.
- Seleccionar la altura mediante un control deslizante.
- Aumentar o disminuir el peso con botones.
- Calcular el IMC automáticamente al pulsar el botón.
- Mostrar el resultado del cálculo.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3

## Diseño

La aplicación cuenta con una interfaz personalizada con colores naturales, iconos y tarjetas para organizar la información.

## Objetivo del proyecto

El objetivo es desarrollar una aplicación Android que permita practicar la creación de interfaces con Jetpack Compose, la gestión de estados y la realización de cálculos a partir de los datos introducidos por el usuario.
